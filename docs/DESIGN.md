# TraceFence interface

2026-10-27. Revised after Dallas rejected the original promotional copy and layout.

The user is reviewing a failed agent run. The page should help them inspect calls and keep the input format nearby. We compared a single full-width table with a split input/results workspace and selected the split workspace. It retains room for reasons while users prepare their input.

Use a compact application header, a page title that names the task, an input pane and a call table. Counts belong in a small summary row. Reserve amber for calls that need review and green for completed writes. Use the existing system and monospace fonts; keep processing local and avoid external font requests. No landing-page headline, decorative badge, oversized counter or ornamental animation.

Copy review uses the installed unslop skill. Design review uses applicable Hallmark guidance. Its marketing-page prescriptions do not override an inspection table's need for density, system fonts or consistent status labels. Human judgment and actual rendered states establish quality; keyword scans and self-assigned scores do not.

Check empty, loaded, invalid and cleared input; sample and personal data; export; light/dark; keyboard focus; 320, 375, 414, 768 and desktop widths. The page must stay within the viewport. The call table may scroll within its labeled region on small screens. Show technical limits where they affect replay decisions.
