Trace format

Each call needs these fields:

id
Unique call ID
tool
Tool name
effect
read / write / unknown
status
succeeded / failed / timeout / unknown
arguments
JSON object

idempotency_key is optional. In CSV, store arguments as a JSON string.

Effects and outcomes come from your trace. Confirm uncertain writes in the destination system before retrying.
