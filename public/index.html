Input format

Each row needs a unique id, tool, declared effect (read/write/unknown), status (succeeded/failed/timeout/unknown), and an arguments object. Optional: idempotency_key.

CSV: use a JSON object string in the arguments cell. Effects must be supplied explicitly.

The tool trusts the trace's declarations. It does not verify destination state, infer permissions, execute calls or guarantee exactly-once delivery.
